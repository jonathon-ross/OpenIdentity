# OpenIdentity Java SDK 0.1.0

This is the first production release of the OpenIdentity Java SDK.

## Protocol compatibility

- SDK: **0.1.0**
- Protocol: **OpenIdentity Protocol v0.1.1**
- Java: **21+**

The release is independently checked against the frozen v0.1.1 normative artifacts and their published SHA-256 manifests.

## Included modules

- `openidentity-core`
- `openidentity-cbor`
- `openidentity-crypto`
- `openidentity-operations`
- `openidentity-credentials`
- `openidentity-conformance`

## Verification

Before this release is tagged, the repository release gate must pass from a clean worktree:

```bash
./tools/release-gate.sh
```

See `docs/API_GUIDE.md` for API usage and `CHANGELOG.md` for the complete release scope.
