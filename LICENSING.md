# OpenIdentity Licensing

OpenIdentity uses the Apache License, Version 2.0 (`Apache-2.0`) as the repository-wide license. The full license text is in `LICENSE`.

## Scope

Unless a file explicitly states otherwise, Apache-2.0 applies to the entire OpenIdentity repository, including protocol specifications under `docs/` and `spec/`; CDDL schemas; JSON-LD contexts and vocabulary resources; normative conformance vectors and checksums; source code; reference/vector tooling; independent verifiers; examples; repository documentation; and website/deployment material.

OpenIdentity may therefore be implemented, used, modified, distributed, and commercialized subject to Apache-2.0.

## Canonical protocol versus forks

Apache-2.0 permits modification and derivative works. A modified specification, schema, vector set, or implementation does not thereby become an official OpenIdentity protocol release. Canonical releases are identified by the official OpenIdentity project repository, release/tag, normative artifacts, and published integrity data.

Forks and derivative works should clearly identify modifications as required by Apache-2.0 and must not imply that modified protocol behavior is an official OpenIdentity release.

## Normative authority

Licensing does not determine protocol authority. OpenIdentity uses this order:

1. normative specification documents;
2. current normative CDDL schemas;
3. normative conformance vectors and published checksums;
4. independently verified reference behavior;
5. implementation/reference code;
6. comments, examples, generated artifacts, and assumptions.

`test-vectors/generated/` contains development/reference output and is not normative merely because it uses the same license.
