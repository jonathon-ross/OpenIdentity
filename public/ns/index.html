Terms

verificationPolicy
Projected verification-combination policy. JSON term: openIdentityVerificationPolicy.
appliesTo
Verification relationship to which the policy applies.
threshold
Number of distinct qualifying methods required.
Single
Single-method policy.
Threshold
m-of-n verification policy.
OpenIdentityCredential
W3C-facing type for a deterministic projection of a native OI-003 credential.
credentialProfile
Identifies the immutable OI-003 Credential Profile governing subject syntax, claims, semantics, and interoperability projection rules. JSON term: openIdentityCredentialProfile.
issuanceStateHash
Identifies the exact historical authoritative OpenIdentity IdentityState whose AssertionPolicy authorized credential issuance. JSON term: openIdentityIssuanceStateHash.
securedCredential
Carries the Multibase representation of the exact canonical native OI-003 SecuredCredential bytes in the W3C projection. JSON term: openIdentitySecuredCredential.
